多语言代码缺陷修复 Agent
GitHub：github.com/mengqing88/code-repair-agent
项目简介：面向多语言代码问题排查，串联问题复现、代码分析、历史经验查找、补丁生成、隔离测试与人工审核，形成可追踪、可恢复的修复流程；全量修复率由单一 Agent 的 42% 提升至 98%。
技术栈：Python、FastAPI、LangGraph、ReAct、MCP、Function Calling、Qdrant、BM25、Cross-Encoder、ONNX Runtime、DirectML、Git worktree、Docker
  • 多 Agent 工作流：基于 LangGraph 编排复现、调查、经验检索、补丁生成、验证与审查，由调度节点协调执行，角色间通过结构化消息传递结果；以 ReAct 驱动按需取证，通过检查点和操作回执保存进度，中断后核对执行结果再恢复，拦截旧 worker 回写，对结果不明的写操作暂停处理。在自建 120 例上，人工接受的有效补丁由 54 例增至 102 例。
  • 修复经验复用：将人工接受的修复与拒绝原因分开保存，按账号、仓库、语言、路径及依赖版本筛选，通过 Qdrant 向量与 BM25 召回、加权排名融合及 Cross-Encoder 重排获取相关经验；外部案例先审核后入库，可确认的行为退化经对照测试与人工批准后转为回归用例，避免后续修复重复引入已知问题。同一用户长期使用后，修复率较冷启动提升 50%。
  • 上下文与推理优化：发送前检查完整请求长度，保留任务规则、候选补丁和近期工具结果，本地压缩旧工具历史；缓存重复查询与候选的重排分数，以 ONNX Runtime、DirectML 加速重排并保留 CPU 降级；JSON 纠错复用已有工具结果，结合预算限制与重复动作检测，减少重复推理和无进展重试。单任务耗时降低 80%，Token 成本降低 50%，无效补丁率由 18% 降至 2%。
  • 补丁执行与验收：限制模型本地工具代码读取和经验检索，由固定节点应用补丁，在 Docker 中执行复现与回归；定向测试须在旧实现失败、补丁实现通过，并重跑原复现脚本，禁止修改受保护测试；审查结论绑定补丁哈希，通过独立审查与人工接受后才保存成功经验。50 轮受控审查共判定 200 个补丁：错误补丁 23/23 被拒，正确补丁 177/177 通过，零误拒。
团队知识库智能问答系统
GitHub：github.com/mengqing88/knowledge-agent
项目简介：面向团队制度、流程与技术资料查询，构建带成员权限、文档版本管理、证据核验和人工审核的知识库问答系统。
技术栈：Python、FastAPI、PostgreSQL、Milvus、Redis、Celery、LangGraph、LlamaIndex、BM25、本地 BGE
  • 检索与证据选择：针对中文表达差异与复合问题证据遗漏，采用整块 BM25、短窗口 BM25 与 Milvus 向量三路召回，结合术语扩展、本地 BGE 重排及原文邻块补全，在限定上下文内兼顾不同子问题；召回与选择方案在同一开发集、固定返回 12 块的离线对照中，使证据 Recall@12 由 65.1% 提升至 95.35%。
  • 权限与版本：以三级 RBAC 控制成员、文档和答案访问，支持十类格式入库；文档新版本完成解析与索引后再切换，失败时保留旧版。执行和发布前复核成员权限及资料版本，答案引用可追溯至原文块、解析版本和文件哈希。
  • Agent 问答与核验：基于 LangGraph 编排问题规划、检索、分析与核验，按需通过 MCP 读取本人项目运行日志，将工具结果与文档证据统一纳入引用检查；按子问题判断证据是否充分，缺证时有限补检，仍不足则收窄或拒答，经人工审核后发布。
  • 异步执行与调用控制：通过幂等键、任务租约和执行标识防止重复创建任务、旧执行覆盖结果及答案重复；模型请求发送前重新检查任务状态与预算，使用 Redis Lua 在多个 worker 间共享请求及 Token 配额，事件流按序号支持断线续传。
